# URL Shortener Service

A single-process, dependency-free URL shortener with a REST API, pluggable persistence
(in-memory or SQLite), click analytics, and built-in rate limiting — structured so each
layer can scale out independently. Generated by the Agentic SDLC system.

## Run it

```bash
python -m url_shortener.server        # serves on http://127.0.0.1:8000 (in-memory store)
SHORTENER_STORE=sqlite SHORTENER_DB_PATH=shortener.db python -m url_shortener.server   # durable
```

Environment: `SHORTENER_HOST`, `SHORTENER_PORT`, `SHORTENER_BASE_URL`, `SHORTENER_STORE`
(`memory` | `sqlite`), `SHORTENER_DB_PATH`.

### Rate limiting

Every client (identified by IP address) is subject to per-endpoint sliding-window limits.
Responses to limited routes carry `X-RateLimit-Limit`, `X-RateLimit-Remaining` and
`X-RateLimit-Reset` headers; going over budget returns `429 Too Many Requests` with a
`Retry-After` header and a JSON error body.

| Env var | Default | Applies to |
| --- | --- | --- |
| `SHORTENER_RATE_LIMIT_SHORTEN` / `SHORTENER_RATE_WINDOW_SHORTEN` | 10 / 60s | `POST /api/shorten` |
| `SHORTENER_RATE_LIMIT_REDIRECT` / `SHORTENER_RATE_WINDOW_REDIRECT` | 100 / 60s | `GET /<code>`, `GET /api/stats/<code>` |
| `SHORTENER_RATE_LIMIT_ADMIN` / `SHORTENER_RATE_WINDOW_ADMIN` | 30 / 60s | `/admin/*` |
| `SHORTENER_TRUSTED_PROXIES` | *(empty)* | comma-separated peer IPs allowed to set `X-Forwarded-For` |

Rules can also be hot-reloaded at runtime (no redeploy) via
`PUT /admin/config/rate-limits/{ruleName}` with a JSON body
`{"limit": <int>, "window_seconds": <number>}`. Current rule config and allow/deny
counters are visible at `GET /admin/metrics` for monitoring and abuse detection.

The limiter is single-instance/in-memory by default but implemented behind a small
`RateLimiterStore` interface (see `url_shortener/ratelimit.py`) so it can be swapped for a
shared store (e.g. Redis) if the service is horizontally scaled.

## Try it

```bash
curl -X POST http://127.0.0.1:8000/api/shorten \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/some/long/path"}'
# -> {"code": "...", "short_url": "http://.../<code>", ...}

curl -i http://127.0.0.1:8000/<code>          # 302 redirect
curl http://127.0.0.1:8000/api/stats/<code>   # click analytics
curl http://127.0.0.1:8000/admin/metrics      # rate-limit rules + counters
```

## Test it

```bash
python -m unittest discover -s tests -v
```

## Layout

| Path | Responsibility |
| --- | --- |
| `url_shortener/base62.py` | id <-> slug codec |
| `url_shortener/store.py` | in-memory + SQLite backends |
| `url_shortener/service.py` | validation, shorten, resolve, stats |
| `url_shortener/analytics.py` | click aggregation |
| `url_shortener/ratelimit.py` | rate limiting (sliding window, metrics, hot-reload) |
| `url_shortener/api.py` | WSGI HTTP adapter |
| `url_shortener/server.py` | dev server entrypoint |
| `openapi.yaml` | API contract |
